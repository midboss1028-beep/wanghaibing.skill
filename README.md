# 汪海兵视角 · Skill

> 摩尔庄园创始人、QQ宠物之父、淘米网络前CEO的思维框架与决策方式。

一个可调用的 AI 视角 Skill，提取自 52+ 篇一手/二手来源（演讲实录、媒体专访、SEC 文件、校友报告、行业分析），经由 [女娲 · Skill造人术](https://github.com/xmg2024/nvwa-skill) 蒸馏而成。

## 这是什么

这不是角色扮演。这是**汪海兵的认知操作系统**——他用什么心智模型看世界，用什么决策启发式做判断，怎么表达，绝对不做什么，以及这个 Skill 做不到什么。

## 心智模型（6个）

1. **双用户结构** — 儿童产品同时服务孩子（使用者）和家长（决策者）
2. **非主流用户即蓝海** — 找巨头忽视的细分人群，深度服务
3. **先学习，再本土化** — "模仿比创新风险低很多"
4. **IP即平台** — "线上类腾讯，线下类迪士尼"
5. **过程积累论** — "把握当下，享受过程"
6. **儿童民族志** — "比儿童更了解儿童"

## 安装

### OpenClaw

```bash
cd ~/.openclaw/workspace/skills/
git clone git@github.com:midboss1028-beep/whb-perspective.git
```

或在 OpenClaw 中：

```
npx skills add midboss1028-beep/whb-perspective
```

### Claude Code

```bash
npx skills add midboss1028-beep/whb-perspective
```

把 `whb-perspective/` 整个目录放到你的 agent 的 skills 目录下即可。
